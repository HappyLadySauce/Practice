# 积分获取与导出功能 - 实现总结

## 已完成的修改

### 1. login_handler.py

#### 导入模块更新
- 添加 `import re` 用于正则表达式处理

#### login() 方法修改
- **返回值类型**：从 `Tuple[bool, str]` 改为 `Tuple[bool, str, float | None]`
- **返回格式**：`(登录是否成功, 消息, 积分值)`
- **新增逻辑**：登录成功后调用 `fetch_user_points()` 获取积分

#### 新增 fetch_user_points() 方法
**功能**：访问积分页面并提取用户积分

**实现特点**：
1. **多策略定位**：使用 4 种不同的选择器策略尝试定位积分元素
   - CSS Selector: `.score-value`, `.points-value`, `.integral-num`, `.score-num`
   - XPath: 通过"我的积分"文本定位
   - XPath: 查找包含数字的相关元素
   - XPath: 查找短文本数字元素

2. **备用方案**：如果元素定位失败，从页面源码中使用正则表达式提取
   - 匹配模式：`我的积分[^0-9]*(\d+\.?\d*)`
   - 匹配模式：`当前积分[^0-9]*(\d+\.?\d*)`
   - 匹配模式：`积分[^0-9]*(\d+\.?\d*)`

3. **调试功能**：
   - 自动保存调试截图：`debug_points_YYYYMMDD_HHMMSS.png`
   - 详细日志输出每个策略的尝试过程
   - 显示找到的原始文本和提取的数值

4. **错误处理**：所有异常都被捕获并记录，返回 `None` 表示获取失败

### 2. main.py

#### 导入模块更新
- 添加 `import os` 用于文件路径处理
- 添加 `from datetime import datetime` 用于时间戳

#### SmartEduGUI 类修改

**新增实例变量**：
```python
self.points_data: list[dict] = []
```
用于存储所有账号的积分信息，格式：
```python
{
    "account": "账号",
    "points": 10.2 或 "获取失败",
    "fetch_time": "2026-01-29 10:30:15"
}
```

**_run_batch_login() 方法修改**：
1. 每次开始前清空 `points_data` 列表
2. 更新登录调用：`ok, msg, points = self.login_handler.login(account, password)`
3. 登录成功后记录积分信息到 `points_data`
4. 日志输出增加积分信息显示
5. 批量处理完成后自动调用 `_export_points_to_excel()`

**新增 _export_points_to_excel() 方法**：
**功能**：将收集的积分数据导出为 Excel 文件

**实现特点**：
1. **表格结构**：
   - 表头：账号、积分、获取时间
   - 表头样式：加粗显示
   - 自动调整列宽（最大50字符）

2. **文件命名**：`积分数据_YYYYMMDD_HHMMSS.xlsx`

3. **保存位置**：
   - 优先保存到桌面
   - 如果桌面不存在，保存到当前目录

4. **用户提示**：
   - 导出成功：弹出提示框显示文件路径
   - 导出失败：显示错误信息

## 数据流程

```
用户点击"开始批量登录"
    ↓
读取 Excel 账号列表
    ↓
遍历每个账号
    ↓
调用 login(account, password)
    ├─ 打开浏览器
    ├─ 输入账号密码
    ├─ 处理滑块验证
    ├─ 检查登录结果
    └─ 如果成功 → 调用 fetch_user_points()
        ├─ 访问积分页面
        ├─ 尝试多种策略定位元素
        ├─ 提取积分数值
        ├─ 保存调试截图
        └─ 返回积分值
    ↓
记录积分信息到 points_data
    ↓
显示日志（包含积分）
    ↓
所有账号处理完成
    ↓
调用 _export_points_to_excel()
    ├─ 创建 Excel 工作簿
    ├─ 写入表头和数据
    ├─ 调整列宽
    ├─ 保存到桌面
    └─ 弹出提示框
```

## 技术亮点

### 1. 鲁棒性
- 多策略元素定位，提高成功率
- 完善的异常处理，不会因单个账号失败而中断
- 备用提取方案（正则表达式）

### 2. 可调试性
- 自动保存截图，便于分析页面结构
- 详细的日志输出，记录每个步骤
- 清晰的错误信息提示

### 3. 用户友好
- 自动选择保存位置（桌面优先）
- 弹出提示框显示操作结果
- 时间戳文件命名，避免覆盖

### 4. 数据完整性
- 记录获取时间，便于追踪
- 失败情况标记为"获取失败"而非跳过
- Excel 格式化（加粗表头、自动列宽）

## 兼容性

- Python 3.10+（使用了 `float | None` 语法）
- 现有依赖无需额外安装（openpyxl、selenium 等）
- Windows/Linux/Mac 通用（路径处理使用 os.path）

## 已知限制

1. **串行处理**：账号是逐个处理的，不支持并行
2. **浏览器关闭**：每个账号处理完就关闭浏览器
3. **元素定位**：如果页面结构大幅改变，可能需要更新选择器
4. **等待时间**：固定等待时间，不够智能
