# 积分获取与导出功能测试说明

## 功能概述

已完成以下功能的实现：
1. ✅ 登录成功后自动访问积分页面并获取用户积分
2. ✅ 批量处理所有账号并收集积分信息
3. ✅ 自动导出积分数据为 Excel 文件（包含账号、积分、获取时间）

## 测试步骤

### 1. 准备测试数据
确保 `账号密码列表.xlsx` 文件包含有效的账号和密码：
- 第一列：账号
- 第二列：密码
- 从第2行开始（第1行是表头）

### 2. 运行程序
```bash
python main.py
```

### 3. 执行批量登录
1. 点击"选择 Excel 文件"按钮，选择账号密码文件
2. 点击"开始批量登录"按钮
3. 观察日志输出，确认每个账号的登录状态和积分获取情况

### 4. 检查结果

正在访问积分页面...

[批量-成功] user1 -> 登录成功, 积分: 10.2

#### Excel 文件
- 文件位置：桌面（如果桌面不可访问则在当前目录）
- 文件名格式：`积分数据_20260129_103015.xlsx`
- 文件内容：

| 账号 | 积分 | 获取时间 |

| user1 | 10.2 | 2026-01-29 10:30:15 |

## 调试功能

### 自动截图
程序会在积分页面自动保存截图，文件名格式为：
```
debug_points_20260129_103015.png
```

如果积分获取失败，可以查看这些截图来分析页面结构。

### 详细日志
日志中会显示：
1. 每个定位策略的尝试过程
2. 找到的元素文本内容
3. 提取的积分数值
4. 任何异常信息

## 常见问题排查

### 问题1：积分显示为"获取失败"

**可能原因：**
- 积分页面元素定位失败
- 页面加载时间不足
- 页面结构发生变化

**排查步骤：**
1. 查看调试截图 `debug_points_*.png`，确认页面是否正常加载
2. 检查日志中的"尝试策略"输出，查看哪个策略最接近
3. 如果页面结构改变，需要更新 `login_handler.py` 中的 `fetch_user_points()` 方法

**手动分析页面结构：**
1. 登录后手动访问 `https://basic.smartedu.cn/user/myIncentives`
2. 按 F12 打开开发者工具
3. 使用"元素选择器"工具（或 Ctrl+Shift+C）点击积分数字
4. 查看元素的 class、id 等属性
5. 更新代码中的选择器

### 问题2：页面加载超时

**解决方法：**
增加等待时间，修改 `login_handler.py` 中的：
```python
wait = WebDriverWait(self.driver, 15)  # 改为 30
time.sleep(2)  # 改为 5
```

### 问题3：滑块验证失败

这是登录阶段的问题，与积分获取无关。如果滑块验证失败，积分也无法获取。

### 问题4：Excel 导出失败

**可能原因：**
- 桌面路径不存在
- 文件权限问题
- openpyxl 库未安装

**解决方法：**
1. 检查桌面路径是否存在
2. 确保有写入权限
3. 安装或更新 openpyxl：`pip install openpyxl`

## 代码结构说明

### login_handler.py
- `login()` 方法：返回值改为 `(成功/失败, 消息, 积分值)`
- `fetch_user_points()` 方法：访问积分页面并提取积分数据
  - 使用多种策略定位元素
  - 自动保存调试截图
  - 支持正则表达式提取数字

### main.py
- `points_data` 列表：存储所有账号的积分信息
- `_run_batch_login()` 方法：批量登录并收集积分
- `_export_points_to_excel()` 方法：导出积分数据为 Excel

## 性能优化建议

### 当前实现
- 每个账号登录后打开新浏览器
- 登录、获取积分、关闭浏览器
- 串行处理所有账号

### 优化方向（可选）
1. 减少等待时间（如果网络速度快）
2. 批量处理时显示进度条
3. 支持失败重试机制
4. 支持断点续传（保存中间结果）

## 注意事项

1. **浏览器窗口**：获取积分时浏览器会短暂打开然后自动关闭
2. **调试截图**：会在当前目录生成多个截图文件，可定期清理
3. **网络连接**：确保网络稳定，避免页面加载超时
4. **账号安全**：导出的 Excel 不包含密码（仅账号、积分、时间）
